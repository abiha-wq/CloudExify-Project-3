# 🦷 Dentiva — Dental Clinic Landing Page
A modern and responsive dental clinic landing page designed to provide a clean, professional, and user-friendly online experience for patients.
##  Project Overview
**Dentiva** is a front-end dental clinic website built with HTML, CSS, JavaScript, and Bootstrap. The website presents dental services, clinic information, statistics, pricing plans, testimonials, FAQs, and appointment booking in a modern and responsive interface.
##  Features
-  Modern Hero/Landing Section
-  Six Dental Service Cards
-  Animated Statistics Counters
-  About Section with Lead Dentist Profile
-  Before & After Treatment Section
-  Patient Testimonials
-  Pricing Plans with a Highlighted Popular Plan
-  FAQ Accordion
-  Appointment Booking Modal/Form
-  Responsive Design for Desktop, Tablet, and Mobile
-  Smooth Navigation Between Sections
-  Client-Side Appointment Form Validation
-  Clean and Modern Dental-Themed UI
##  Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling, layouts, animations, and responsiveness
- **JavaScript (ES6+)** — Interactive functionality and form validation
- **Bootstrap 5** — Responsive grid, modal, accordion, and utilities
- **Bootstrap Icons** — Interface and service icons
- **Google Fonts** — Typography
- **Visual Studio Code** — Development environment
